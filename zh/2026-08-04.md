## 头条深度

### OpenAI 如何构建 GPT Live——让 AI 语音对话像真人一样的六个月工程

**事件**：8 月 3 日，OpenAI 发布 GPT Live 语音系统的完整技术解析。GPT Live 是第三代语音架构，其核心变革是移除了"轮次检测器"（turn detector）——此前所有语音 AI 系统中决定"用户是否说完"的小型模型——代之以全双工语音模型，可以同时听和说。

这篇工程博文详述了从轮次架构到流式架构的完整转变：

**从轮次到流式**：此前的语音 AI 继承了文本 LLM 的轮次本质，每次交互表示为离散音频块。级联系统（STT → LLM → TTS）串行执行，延迟高且丢失语气和节奏信息。语音到语音模型改进了直接处理音频的能力，但仍然依赖轮次检测器决定何时开始推理。GPT Live 将语音模型置于对话控制中心：音频流入流出模型，深度推理和工具调用异步进行。

**持续推理的关键设计**：
- **媒体与逻辑分离**：音频在专用快速路径上运行，工具调用和后端服务通过异步 RPC 边界隔离——慢速工具调用不会阻塞媒体流
- **Go 重写**：媒体前端和推理逻辑从 Python asyncio 迁移到 Go，新系统的 p95 延迟达到原系统的 p50 水平
- **WebRTC 传输**：利用 WebRTC 的丢包容错、时钟漂移修正和音频拉伸技术保证流畅交付
- **无缝模型切换**：当需要迁移会话或压缩上下文时，系统并行预热新实例，在完全就绪后切换——用户无感知中断

**异步委托机制**：GPT Live 将"说话"和"思考"解耦。语音模型维持对话流畅，同时异步调用 GPT-5.5 等前沿模型进行深度推理。系统在语音会话开始时就预初始化前沿模型的推理会话，配合 prompt 缓存和会话亲和性将委托延迟降至最低。

**WARP 协议**：为解决 WebRTC 启动握手轮次过多的问题，OpenAI 开发了 WebRTC Abridged Roundtrip Protocol（WARP），将媒体和数据启动从 6 次网络往返压缩到 1 次。WARP 已作为开放规范提交 IETF，并已被 libwebrtc 和 Pion 实现。

**影子测试**：在正式上线前，OpenAI 运行了静默测试——将部分生产流量路由到新系统进行只读推理，暴露了真实负载下的容量瓶颈、地理延迟分布和长会话内存压力等问题。

**链接**：[原文](https://openai.com/index/continuous-voice-interaction-with-gpt-live/) | [中文翻译](../translations/2026-08-04/openai-gpt-live-voice-architecture.md) *(AI 译)*

**为什么重要**：这是语音 AI 从"伪对话"走向"真对话"的架构分水岭。全双工模型意味着 AI 不再需要猜测你有没有说完——它一直在听，也一直在说。异步委托架构解决了"快速响应"与"深度推理"的矛盾，这在业界是首次大规模生产部署。而 WARP 协议的开放标准化意味着整个实时通信行业都可能受益。

**Alex 的分析**：三个层面值得深挖。

第一，Go 重写的决定值得关注。Python asyncio 在 I/O 密集场景的延迟可预测性一直有上限。OpenAI 用 Go 重写核心媒体路径并公开承认 p95 → p50 的跨越，等于间接承认了 Python 在硬实时场景的结构性劣势。这对整个 AI 基础设施社区的技术选型有风向标意义。

第二，"影子测试"方法论非常聪明。在真实生产流量上做只读推理测试——不是基准测试，不是压力测试，而是真实用户的真实会话——这暴露出了负载测试永远无法覆盖的问题：长会话内存泄漏、重连时的状态恢复竞争条件、地理分布延迟。这种工程纪律解释了为什么 OpenAI 能在语音体验上拉开差距。

第三，WARP 的开放标准化策略。OpenAI 没有把启动优化当作专有技术，而是提交给 IETF 并推动社区实现。这看似不符合商业利益，但实际上是在建立生态影响力——如果整个行业采用 WARP，OpenAI 的语音产品天然受益于更低的端到端延迟。

## OpenAI

### GPT-5.6 大幅降价：Luna 降 80%，Fast 模式上线

**事件**：7 月 30 日，OpenAI 宣布 GPT-5.6 系列价格调整。GPT-5.6 Luna 降价 80%，至 $0.20/百万输入 token 和 $1.20/百万输出 token；GPT-5.6 Terra 降价 20%，至 $2/$12。同时推出 Fast 模式替代 Priority Processing，GPT-5.6 Sol Fast 模式提供最高 2.5 倍速度提升，价格为标准模式的 2 倍，智能水平不变。

OpenAI 强调的核心论点是：正确的衡量标准不是每百万 token 的价格，而是"完成一项成功任务的成本"——包括时间、重试、监督和错误。一个更强的模型一次做对，最终可能比便宜但需要反复尝试的模型更经济。

**链接**：[原文](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)

**分析**：Luna 降至 $0.20/$1.20 意味着大规模部署 AI 的成本门槛再次大幅下降。OpenAI 明确将此定位为"丰裕智能"战略——让更多工作"值得用 AI 做"。Fast 模式的推出则回应了企业客户对延迟敏感场景的需求。

### 两个 API 设置让 ARC-AGI-3 分数翻三倍

**事件**：7 月 29 日，OpenAI 发布对 ARC-AGI-3 基准测试的分析。GPT-5.6 Sol 在官方 harness 下仅得 13.3%，但开启"保留推理"（retained reasoning）和"上下文压缩"（compaction）两个设置后，分数飙升至 38.3%，同时输出 token 减少到原来的 1/6。

关键发现是：ARC-AGI-3 的官方 harness 在每次游戏动作后丢弃所有私有推理，并使用滚动截断窗口，导致模型每一步都要从零理解游戏。OpenAI 用自己的 Responses API 重新实现 harness，保留模型的思考链和早期记忆后，表现戏剧性改善。人类测试者平均得分约 48%。

**链接**：[原文](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)

**分析**：这篇分析对整个 AI 评测社区有重要方法论意义——基准测试很少只测模型本身，它们测的是"模型 + harness + 提示词 + API 设置"的整个组合。如果你的模型在某个基准上表现差，可能不是模型的问题，而是你没用对设置。

### ChatGPT for Academic Researchers：向 10 万研究者免费开放前沿模型

**事件**：7 月 29 日，OpenAI 宣布 ChatGPT for Academic Researchers 项目，向精选学术机构的 10 万名研究者免费提供前沿模型（包括 GPT-5.6 Sol Pro）。今年夏天从 1 万人开始，已接入普林斯顿高等研究院（IAS）和巴黎高等师范学院（ENS），计划 2027 年扩展至 10 万人。

项目包含 75+ 个生命科学技能（基因分析、蛋白质建模、药物发现）、扩展的深度研究和使用限额、以及专门的培训支持。这是 OpenAI 超过 2.5 亿美元科研投入承诺的一部分。

数据显示，每周约 130 万人使用 ChatGPT 进行高级科学和数学研究，产生约 840 万条消息。AI 使用最密集的研究者（前 20%）比同伴更倾向于让 AI 处理估计需要 4 小时以上人力时间的任务。

**链接**：[原文](https://openai.com/index/chatgpt-for-academic-researchers/)

**分析**：这不仅是公益——OpenAI 在战略性地让科研社区成为其前沿模型的深度用户。当论文开始标注 ChatGPT 的贡献，当研究工具链围绕 OpenAI 的 API 构建，生态锁定效应就自然形成了。

### "构建丰裕智能"——OpenAI 的战略愿景全文

**事件**：7 月 31 日，OpenAI 发布"Building Abundant Intelligence"战略文章，系统阐述其基础设施投资逻辑。

核心论点：AI 基础设施的价值不在于其规模，而在于它让什么成为可能——更强能力的智能，服务更多人，成本更低。这形成正循环：更好的智能 → 更广泛的采用 → 更多投资 → 更好的智能和效率。

关键数据点：
- 模型已覆盖超过 10 亿活跃用户和 200 万企业
- 用户注册 6 个月后日均消息量增长约 50%
- Codex 代理工作占每周输出 token 的 99.8%
- GPT-5.6 Sol 帮助降低端到端服务成本 20%，提升 token 生成效率 15%+

**链接**：[原文](https://openai.com/index/building-abundant-intelligence/)

**分析**：这篇文章是理解 OpenAI 商业逻辑的核心文本。值得注意的细节：Codex 代理工作占 99.8% 周 token 输出——这意味着 OpenAI 的 API 消耗已经从"人类对话"主导转向"代理工作"主导。代理场景的 token 消耗密度远超人类对话，这解释了为什么 OpenAI 对 agent 基础设施投入如此之大。

### AI 如何扩展职场工作边界——"任务跨界"报告

**事件**：7 月 27 日，OpenAI 发布研究报告，分析超过 80 万条美国 ChatGPT 用户消息后发现：16.8% 的工作相关消息和 43.5% 的职业特定消息涉及属于其他职业的任务。

这种"任务跨界"（task crossover）在客服（77%）、设计师（75%）、人力资源（69%）、法务（56%）和市场营销（53%）领域最为显著。小企业的跨界比例更高——2-5 人团队的外部任务占比 18.9%，超过 100 人团队降至 16.3%。

营销和工程任务的"外溢"最明显：工程任务占其他职业消息的 7.4%，营销任务占 8.9%。

**链接**：[原文](https://openai.com/index/how-ai-is-expanding-what-people-do-at-work/)

### Health in ChatGPT 正式上线

**事件**：7 月 23 日，OpenAI 推出 Health 功能，美国用户可选择连接 Apple Health 数据和医疗记录，让 ChatGPT 在有上下文的情况下回答健康相关问题。连接的医疗记录和 Apple Health 信息不会被用于训练基础模型或投放广告。

GPT-5.5 Instant 为免费用户提供前沿健康智能，GPT-5.6 Sol 为付费用户提供更强性能。早期测试者反馈最实用的功能是将分散的医疗历史整合为可理解的时间线。

**链接**：[原文](https://openai.com/index/health-in-chatgpt/)

## 趋势观察

本周的 AI 新闻呈现出一条清晰主线：**AI 正在从"能力竞赛"转向"渗透竞赛"**。

OpenAI 同时在做三件事：降低成本（Luna 降 80%）、提升体验（GPT Live 全双工语音）、扩大覆盖（10 万研究者免费、Health 功能、工作场景渗透分析）。这不是孤立的产品发布，而是系统性地降低 AI 使用门槛，让更多人、更多场景用得起、用得自然。
