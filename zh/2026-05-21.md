## 头条深度

### OpenAI 模型自主推翻 Erdős 单位距离猜想，AI 科研从“辅助证明”走向“提出构造”

**事件**：OpenAI 发布研究里程碑 [An OpenAI model has disproved a central conjecture in discrete geometry](https://openai.com/index/model-disproves-discrete-geometry-conjecture/)，称一个内部通用推理模型自主解决了平面单位距离问题中的核心猜想。该问题源自 Paul Erdős 1946 年提出的组合几何问题：在平面上放置 n 个点，最多能有多少对点距离正好为 1？长期以来，数学界普遍认为接近方格构造的增长率已经基本最优；OpenAI 称模型给出了无限族反例，并带来多项式级改进。外部数学家已检查证明，并撰写 companion paper 解释背景与意义。

**为什么它值得做头条**：这条新闻的行业意义大于单个数学结果。AI 过去在数学中的代表性进展多集中在形式化证明、竞赛题、辅助检索和人类主导的证明补全；OpenAI 这次强调的是通用推理模型在没有为该问题专门训练、没有针对单位距离问题设计 scaffold 的情况下，给出原创构造并完成证明。如果这个结果经受住数学共同体的后续审查，它会成为“AI 能否参与前沿科学创造”讨论中的一个强信号。

**关键信息**：
- OpenAI 称内部模型推翻了单位距离问题中广泛相信的 `n^(1+o(1))` 上界猜想
- 新构造对无限多个 n 给出至少 `n^(1+δ)` 个单位距离对；OpenAI 文中提到 Will Sawin 的后续 refinement 可取 `δ=0.014`
- 证明把代数数论中的数域、无限类域塔和 Golod-Shafarevich 理论引入一个初等几何问题
- 外部数学家 Noga Alon、Tim Gowers、Arul Shankar、Jacob Tsimerman 等参与评论或验证；OpenAI 同时提供 proof、companion remarks 和模型 chain-of-thought 的节选版本
- OpenAI 将其定位为“首次由 AI 自主解决某个数学子领域核心知名开放问题”的里程碑

**深度分析**：

这件事最值得关注的地方，不是“AI 终于会做数学题”，而是模型似乎在做数学家真正做的那类事：寻找反例、跨领域迁移工具、构造新对象，并把长链条论证维持到可审查的程度。单位距离问题本身很容易解释，但几十年来难以推进；用深层代数数论工具反攻组合几何，正是人类数学里很典型、也很难自动化的创造性跳跃。

如果把它放进过去一周的行业脉络，OpenAI 的数学结果与 Google 的 Co-Scientist 形成了有趣对照。Google 展示的是多智能体科研工作台：提出假设、辩论、排序、查文献、接入工具和人类验证。OpenAI 展示的是单个前沿推理模型在一个精确定义的问题上产出可被专家审查的原创证明。前者强调科研流程系统化，后者强调模型内部推理能力已经能撞开某些研究问题。

这并不意味着数学家会被替代。恰恰相反，OpenAI 文中也强调人类判断仍然关键：专家选择问题、检查证明、解释意义、追踪新联系。AI 给出的是一种候选发现机制，而数学共同体负责把它变成可靠知识。真正的变化在于搜索空间：人类可能开始让模型探索那些“看起来太偏、太长、太难、太不值得试”的路线，然后再由专家挑出其中有价值的部分。

风险同样明确。一个看似完整的证明只有在专业共同体持续审查后才算站稳；模型 chain-of-thought 是否能充分解释发现路径，也不等同于可复现的科研方法；更重要的是，如果 AI 研究输出开始增多，学术生态需要新的审稿、归属、署名、可验证性和误差处理机制。数学是幸运的，因为证明可检查；生物、医学、材料和工程里的“发现”成本更高，错误也更贵。

今天的判断：AI 科研竞争正在分成两条线。一条是 Google 式的“科研 agent 平台”，把模型接入文献、数据库、实验工具和人类审查；另一条是 OpenAI 式的“前沿推理突破”，让模型直接在清晰问题上提出原创解法。真正有长期价值的系统，可能会把两者合并：既能提出新想法，也能解释、验证、引用、复现，并在高风险领域接受人类治理。

## OpenAI

### 内容溯源升级：OpenAI 采用 C2PA + Google SynthID，并预览公共验证工具

OpenAI 在 5 月 19 日发布 [Advancing content provenance for a safer, more transparent AI ecosystem](https://openai.com/index/advancing-content-provenance/)，宣布强化内容溯源方案：成为 C2PA conforming generator product，把 Content Credentials 做得更容易被平台识别；同时与 Google 合作，在 ChatGPT、Codex 和 OpenAI API 生成的图像中引入 SynthID 隐形水印；并预览面向公众的验证工具，用于检测图像是否包含 OpenAI 来源的溯源信号。

**判断**：这条与 Google 的 I/O 安全更新互相呼应。随着图像、视频和多模态 agent 进入主流产品，行业需要的不再是单一水印，而是元数据、隐形水印、检测工具和跨平台标准的组合。OpenAI 和 Google 在 SynthID 上合作，说明内容真实性已经从单家公司安全功能变成生态基础设施问题。

**链接**：[原文](https://openai.com/index/advancing-content-provenance/)

## NVIDIA

### NVIDIA 把 Deep Research 做成 agent skill：企业研究流程开始模块化

NVIDIA 技术博客发布 [Add a Specialized Deep Research Skill to Agent Harnesses](https://developer.nvidia.com/blog/add-a-specialized-deep-research-skill-to-agent-harnesses/)，介绍如何把 NVIDIA AI-Q 的深度研究能力作为 portable agent skill 暴露给 Claude Code、Codex、LangChain Deep Agents 等 agent harness。文章强调，企业深度研究涉及数据源连接、鉴权、查询路由、提示调优、输出评估和引用保留，AI-Q skill 可让通用 agent 把研究任务委托给本地或托管的 AI-Q server，并返回带引用的结构化报告。

**判断**：这是 agent 工程从“写 prompt”走向“能力模块化”的信号。未来企业不会把所有能力塞进一个 agent，而会把研究、检索、代码、审计、安全、数据处理做成可治理的技能单元。

**链接**：[原文](https://developer.nvidia.com/blog/add-a-specialized-deep-research-skill-to-agent-harnesses/)

## 趋势观察

### AI 行业从“模型能力”转向“可验证的行动能力”

今天的新闻可以压缩成一个主题：AI 正在从生成答案，转向产生可被现实世界采纳的行动和发现。

OpenAI 的离散几何结果代表“可审查的原创推理”；Google I/O 代表“跨入口执行系统”；NVIDIA agent skills 代表“企业能力模块化”；Anthropic + Stainless 代表“agent 连接基础设施”；OpenAI + Google 的内容溯源代表“生成内容的可验证身份”。

这五条线合在一起，说明行业正在补齐同一套栈：

1. **推理**：模型能否保持长链条论证，并提出非平凡构造？
2. **连接**：agent 能否可靠接入 API、工具、企业数据和工作流？
3. **治理**：能力、权限、来源、审计和验证是否成为默认机制？
4. **分发**：能力是否进入搜索、开发工具、企业平台、创作工具和科学工作台？
5. **人类判断**：专家是否仍在问题选择、验证、解释和责任承担上掌握关键位置？

真正的竞争不只是参数、速度或 benchmark，而是“发现或行动能否被信任”。谁能把模型能力、工具连接、来源证明、权限治理和人类审查合在一个闭环里，谁才更可能把 AI 从 demo 推进到生产系统和科研系统。
