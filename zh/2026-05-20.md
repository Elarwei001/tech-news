## 头条深度

### Google 用 Gemini 3.5、Omni 与 Co-Scientist 把“agentic AI”推成一套产品矩阵

**事件**：Google/DeepMind 在 5 月 19 日集中发布多条一手更新：Gemini 3.5 Flash 面向 agent 和 coding 工作流，Gemini Omni Flash 从视频开始推进多模态生成与编辑，Gemini for Science/Co-Scientist 则把多智能体系统用于科研假设生成、辩论、验证和迭代。

**为什么它值得做头条**：今天的重点不是单个 benchmark，而是 Google 正在把 Gemini 变成横跨消费端、开发者、企业和科研场景的执行层。Gemini 3.5 负责复杂任务和编码，Omni 负责多模态创作，Co-Scientist 负责科学发现，Antigravity 和 Gemini API 则承接开发者与企业落地。这是一种平台型打法：让同一模型族出现在用户入口、开发工具、企业 agent 平台和科学工作台里。

**关键信息**：
- Gemini 3.5 Flash 已向 Gemini app、Google Search AI Mode、Google Antigravity、Gemini API、Android Studio、Gemini Enterprise Agent Platform 和 Gemini Enterprise 开放
- Google 称 Gemini 3.5 Flash 面向长周期 agent 任务，在 coding 和 agentic benchmark 上超过 Gemini 3.1 Pro，并强调输出速度优势
- Gemini Omni Flash 支持从图像、音频、视频和文本输入生成高质量视频，并通过自然语言多轮编辑视频；初始面向 Gemini app、Google Flow、YouTube Shorts 和 YouTube Create App 推出
- Gemini for Science 包含 Hypothesis Generation、Computational Discovery、Literature Insights 三类实验工具，背后分别连接 Co-Scientist、AlphaEvolve/ERA 和 NotebookLM
- Co-Scientist 基于 Gemini 的多智能体结构，会生成、辩论、排序、演化科研假设，并调用文献、ChEMBL、UniProt、AlphaFold 等资源支持验证
- DeepMind 表示 Co-Scientist 相关研究发表于 Nature，并已在肝纤维化、ALS、植物免疫、感染病机制等方向进行合作验证

**深度分析**：

Google 今天展示的不是一个产品，而是一条从“理解世界”到“改变工作流”的链路。Gemini 3.5 Flash 把模型定位从回答问题推进到执行长任务：维护代码库、准备财务文档、处理百页级企业材料、调用多个 subagent。Gemini Omni 则把多模态能力从静态图像推进到可对话的视频编辑和生成。Co-Scientist 再把同样的 agent 思路放进科研流程，让 AI 不只是读论文，而是参与提出可测试的科学假设。

这套组合的核心是“可执行的上下文”。过去的 AI 产品常常把用户拖进聊天框；今天的发布则试图把模型放回用户原本工作的地方：搜索、Gemini app、Android Studio、Antigravity、企业 agent 平台、Google Flow、YouTube Shorts、科学实验工具。入口越接近真实工作，模型越有机会从“建议者”变成“协作者”。

Co-Scientist 尤其值得关注，因为它把多智能体系统用于高错误成本领域。科研不是多生成几个想法就算成功，关键在于假设是否新颖、是否有文献和数据支撑、是否能被实验验证。DeepMind 的“想法锦标赛”把生成、同行评审式批判、排序、演化和引用核查串起来，本质上是在尝试为科学 agent 建立一种内部治理机制。这个方向比普通办公 agent 更难，但如果有效，价值也更大。

商业上，Google 的优势不只是模型能力，而是分发面。Gemini 3.5 进入 Search、Gemini app、Antigravity、Android Studio 和企业平台；Omni 进入 YouTube 和 Flow；Gemini for Science 进入 Labs 和 Cloud。这意味着 Google 可以同时测试个人创作、开发者生产力、企业自动化和科学发现四条路径，而不是押注单一入口。

风险也不能忽略。视频生成会继续推高内容真实性、水印与身份滥用压力；科学 agent 如果过度自信，可能把“看似有依据”的假设包装成研究捷径；企业 agent 则需要权限、审计、回滚和人类责任边界。Google 在 Omni 中强调 SynthID，在 Co-Scientist 中强调引用核查和科学家审阅，在 Gemini 3.5 中强调 Frontier safeguards，说明这些不是附属问题，而是产品能否进入高信任工作流的前提。

今天的行业判断很明确：AI 竞争正在从模型发布转向“系统占位”。模型能力仍重要，但真正的差距会体现在谁能把模型接入用户上下文、工具链、数据权限、审核机制和实际交付流程。Google 这轮 I/O 更新，是对这个趋势最密集的一次展示。

## Anthropic

### Anthropic 扩大 frontier AI 对话，把“AI 性格形成”纳入安全工作

Anthropic 发布 [Widening the conversation on frontier AI](https://www.anthropic.com/news/widening-conversation-ai)，称过去数月与宗教、哲学、文化、伦理等群体进行对话，讨论 AI 系统的价值、品格和社会影响。文章特别提到“moral formation of AI systems”：模型从大量文本中学习表达与选择方式，开发者再通过训练强化或抑制某些行为模式，因此需要思考 AI 应当呈现什么样的“品格”。

**判断**：这不是常规产品新闻，但它与 Anthropic 的安全路线高度一致。技术安全不只包括评测、解释性和护栏，也包括模型在压力下如何保持稳定价值取向。值得注意的是，Anthropic 提到曾实验让 Claude 在任务中调用一个提醒自身伦理承诺的工具，并在内部 alignment eval 上降低了若干 misaligned behavior。

### Gemini 3.5 Flash：把速度、coding 和长周期 agent 任务绑在一起

## 趋势观察

### Agent 竞争进入“四层堆栈”：模型、入口、数据、治理

今天的新闻可以合并成一个判断：agent 产品正在从“模型能力展示”走向“四层堆栈”竞争。

1. **模型层**：Gemini 3.5 Flash、Codex、Claude、Co-Scientist 这类系统都在强调长任务、推理、工具调用和多智能体协作。
2. **入口层**：Google 把 Gemini 放进 Search、Gemini app、Antigravity、YouTube、Flow、Android Studio；OpenAI 通过 Dell 贴近企业本地系统；Anthropic 进入 KPMG Digital Gateway。
3. **数据层**：Dell AI Data Platform、KPMG Digital Gateway、ChEMBL/UniProt/AlphaFold、Google Cloud 科研方案都说明 agent 必须靠近高质量上下文。
4. **治理层**：Frontier safeguards、SynthID、科学引用核查、Claude 伦理提醒工具、人类审阅与企业可信框架，正在成为 agent 落地的硬条件。

未来几个月，值得关注的不是谁发布了最多模型，而是谁能把这四层堆栈闭合。真正能改变工作流的 agent，必须既能行动，也能被约束；既能接入数据，也能留下审计链路；既能提高速度，也不把责任边界变成一团雾。
