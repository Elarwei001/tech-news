## 头条深度

### NVIDIA + Microsoft：从 Windows PC 到云端，构建统一的智能体 AI 全栈

**事件**：在 Microsoft Build 2026 和 GTC Taipei（COMPUTEX）上，NVIDIA 和 Microsoft 公布了一项覆盖智能体 AI 全部署谱系的深度合作——从个人设备到云端规模 AI 工厂。

**核心内容**：

- **RTX Spark** — 全球首批专为个人 AI 智能体设计的 Windows PC。笔记本和小型台式机提供 1 PFLOPS AI 算力、最高 128GB 统一内存、全天续航，且不插电时 AI 和图形性能不打折。Microsoft Surface、华硕、戴尔、惠普、联想、微星今秋出货。

- **DGX Station for Windows** — 桌边 AI 超级计算机，搭载 GB300 Grace Blackwell Ultra 桌面超级芯片，748GB 一致性内存、20 PFLOPS FP4 算力，可运行高达 1 万亿参数的前沿模型。华硕、戴尔、技嘉、惠普、微星、超微预计 Q4 出货。

- **NVIDIA OpenShell** — 开源（Apache 2.0）、模型无关的自主智能体安全运行时。已集成至 GitHub Copilot。每个智能体在隔离的沙箱容器中运行，所有出站调用在访问文件、网络或凭证前必须通过策略评估。

- **Microsoft Fabric GPU 加速** — NVIDIA 加速计算内置至 Microsoft Fabric 数据仓库，高并发工作负载下 SQL 执行速度比 CPU 基线快 6 倍。

- **NVIDIA Nemotron 3 Ultra** — 全新的开放前沿推理模型，面向编码、研究和企业工作流中的长时运行智能体，本月上线 Microsoft Foundry。

- **Fairwater Wisconsin AI 工厂** — 已上线运行，数十万块 NVIDIA Grace Blackwell 系统作为单一 AI 工厂。Microsoft 已验证 NVIDIA Vera Rubin 平台用于 Azure 部署。

**深度分析**：这不只是一次合作发布，而是一份架构蓝图。NVIDIA 和 Microsoft 正在构建一个无缝全栈——智能体可以在 RTX Spark 笔记本上本地运行，按需扩展至 DGX Station，或爆发至 Azure 云端，无需更换底层模型或工具链。OpenShell 集成至 GitHub Copilot 尤其关键：它让每一位 Copilot 用户都拥有智能体的安全沙箱，可能大幅加速企业级采用。经济账也很清晰——Vera Rubin 每兆瓦提供 10 倍推理吞吐量，这条成本曲线首次让"永远在线"的企业智能体变得可行。

## Anthropic

### Project Glasswing 更新：已发现超 10,000 个高危漏洞

Anthropic 发布了 Project Glasswing 的详细进展。一个月内，合作伙伴共发现超过 10,000 个高危/严重漏洞，多家合作伙伴的漏洞发现速度提升了 10 倍以上。

核心发现：
- Cloudflare 在关键系统中发现 2,000 个漏洞（400 个高危/严重），误报率优于人类测试者
- Mozilla 在 Firefox 150 中发现并修复了 271 个漏洞——比用 Claude Opus 4.6 在 Firefox 148 中发现的多 10 倍以上
- 英国 AI 安全研究所报告 Mythos Preview 是首个端到端解决其两个赛博靶场的模型
- 开源扫描：1,000+ 项目中估计有 6,202 个高危/严重漏洞；分诊后真阳性率 90.6%
- 一家 Glasswing 合作银行使用 Mythos Preview 检测并阻止了一笔 150 万美元的欺诈性电汇

瓶颈不再是发现漏洞，而是人类验证、报告和修补它们的能力。Anthropic 已面向企业客户推出 Claude Security 公测版，三周内已修补 2,100+ 漏洞。

### 编码智能体在社会科学中的应用：首份大规模调查

Anthropic 经济研究团队调查了 1,260 名定量社会科学家的 AI 和编码智能体使用情况。核心结论：81% 尝试过 AI 聊天机器人，但仅 20% 将编码智能体（如 Claude Code）纳入日常工作。

核心发现：
- 差距显著：使用典型男性名的研究者采用编码智能体的比例是使用典型女性名者的两倍；顶尖大学研究者采用率高 40%
- Claude Code 占主导（86% 的编码智能体用户使用）
- 编码智能体用户发布的工作论文多约 75%，启动项目多约 10%，但期刊投稿量尚无增长
- 研究者对 AI 提升个人生产力持乐观态度（88% 在 5/10 以上），但对 AI 改善整个社会科学领域信心不足——70% 对个人生产力的乐观程度高于对领域整体影响的乐观程度

**链接**：[原文](https://www.anthropic.com/research/coding-agents-social-sciences)

## 趋势观察

### 智能体全栈正在固化

本周三项独立的发展指向同一结论：智能体 AI 的基础设施层正快速成熟为一个连贯的全栈。

1. **NVIDIA + Microsoft** 正在构建从硬件到软件到云端的智能体连续体——从 RTX Spark 笔记本到 Azure AI 工厂，OpenShell 提供安全运行时。

2. **Anthropic 的编码智能体研究**显示社会科学家中 20% 的采用率，Claude Code 占主导。生产力提升真实存在，但集中在早期管道工作——期刊投稿的"最后一英里"尚未受到影响。

共同主线：2026 年是智能体 AI 从演示走向部署基础设施的转折年。构建部署层的公司（NVIDIA、Microsoft、Anthropic）正在为一个多年的平台变革做布局。
