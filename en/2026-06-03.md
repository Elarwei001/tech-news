## Headline

### NVIDIA + Microsoft: A Unified Stack for Agentic AI — From Windows PCs to the Cloud

**What happened**: At Microsoft Build 2026 and GTC Taipei at COMPUTEX, NVIDIA and Microsoft unveiled a sweeping partnership that covers the entire agentic AI deployment spectrum — from personal devices to cloud-scale AI factories.

**The details**:

- **RTX Spark** — The world's first Windows PCs purpose-built for personal AI agents. These laptops and small desktops deliver 1 petaflop of AI performance, up to 128GB unified memory, all-day battery life, and full AI+graphics performance unplugged. Systems from Microsoft Surface, ASUS, Dell, HP, Lenovo, and MSI arrive this fall.

- **DGX Station for Windows** — A deskside AI supercomputer powered by the GB300 Grace Blackwell Ultra Desktop Superchip with up to 748GB coherent memory and 20 petaflops of FP4 performance. Runs frontier models up to 1 trillion parameters for always-on enterprise agents. Expected Q4 from ASUS, Dell, GIGABYTE, HP, MSI, and Supermicro.

- **NVIDIA OpenShell** — An open-source (Apache 2.0), model-agnostic secure runtime for autonomous agents. Now integrated into GitHub Copilot. Each agent runs in an isolated sandboxed container; every outbound call is evaluated against policy before it can reach files, networks, or credentials.

- **Microsoft Fabric GPU Acceleration** — NVIDIA accelerated computing built into Microsoft Fabric Data Warehouse, delivering SQL execution up to 6x faster than CPU baseline for high-concurrency workloads.

- **NVIDIA Nemotron 3 Ultra** — A new open frontier reasoning model for long-running agents across coding, research, and enterprise workflows, available this month on Microsoft Foundry.

- **Fairwater Wisconsin AI Factory** — Now live, running hundreds of thousands of NVIDIA Grace Blackwell systems as a single AI factory. Microsoft has also validated the NVIDIA Vera Rubin platform for deployment across Azure data centers.

**Analysis**: This is not just a partnership announcement — it's an architecture blueprint. NVIDIA and Microsoft are building a seamless stack where agents can run locally on RTX Spark laptops, scale up to DGX Station deskside, or burst to Azure cloud without changing the underlying model or toolchain. The integration of OpenShell into GitHub Copilot is particularly significant: it gives every GitHub Copilot user a secure sandbox for agents, which could accelerate enterprise adoption dramatically. The economics are also telling — Vera Rubin delivers 10x inference throughput per megawatt, a cost curve that makes always-on enterprise agents viable for the first time.

## Anthropic

### Project Glasswing Update: 10,000+ Critical Vulnerabilities Found

Anthropic published a detailed update on Project Glasswing, its initiative to secure the world's most critical software using Claude Mythos Preview. In one month, partners collectively found more than 10,000 high- or critical-severity vulnerabilities. Several partners report a 10x increase in bug-finding rate.

Key findings:
- Cloudflare found 2,000 bugs (400 high/critical) with a false positive rate better than human testers
- Mozilla found and fixed 271 vulnerabilities in Firefox 150 — over 10x more than with Claude Opus 4.6 in Firefox 148
- The UK's AI Security Institute reports Mythos Preview is the first model to solve both of their cyber ranges end-to-end
- In open-source scanning: 6,202 high/critical vulnerabilities estimated across 1,000+ projects; 90.6% true positive rate after triage
- A Glasswing partner bank used Mythos Preview to detect and prevent a fraudulent $1.5M wire transfer

The bottleneck is no longer finding vulnerabilities — it's the human capacity to verify, report, and patch them. Anthropic released Claude Security in public beta for Enterprise customers, which has been used to patch over 2,100 vulnerabilities in three weeks.

**Links**: [Anthropic Research](https://www.anthropic.com/research/glasswing-initial-update)

### Coding Agents in the Social Sciences: First Large-Scale Survey

Anthropic's economic research team surveyed 1,260 quantitative social scientists about AI and coding agent use. The headline: 81% have tried AI chatbots, but only 20% have adopted coding agents (like Claude Code) into regular work.

Key findings:
- Sharp disparities: twice as many researchers with typically male names use coding agents vs. those with female names; researchers at top universities are 40% more likely to use them
- Claude Code is the dominant tool (86% of coding agent users)
- Coding agent users post ~75% more working papers and start ~10% more projects than peers, but show no increase in journal submissions yet
- Researchers are optimistic about AI raising productivity (88% above 5/10) but less confident about AI improving social science as a whole — 70% are more optimistic about personal productivity than about field-level impact

**Links**: [Anthropic Research](https://www.anthropic.com/research/coding-agents-social-sciences)

## NVIDIA

**Links**: [NVIDIA Blog](https://blogs.nvidia.com/blog/jetson-agentic-ai-physical-world/)

### NVIDIA Factory Operations Blueprint (FOX)

A reference design for building autonomous factory manager agents. Built with NemoClaw, AI-Q Blueprint, and Nemotron open models. Taiwan manufacturers Foxconn, Pegatron, Advantech, and Wistron are first to deploy. Foxconn projects 80% improvement in root cause analysis time and 15% increase in labor productivity using MoMClaw (manufacturing operations multi-agent system).

**Links**: [NVIDIA Blog](https://blogs.nvidia.com/blog/factory-operations-fox-blueprint-ai-brain/)

### Cosmos 3: Open World Foundation Model for Physical AI

NVIDIA Cosmos 3 combines vision reasoning, multimodal generation, and action prediction in a single model. The mixture-of-transformers architecture uses a reasoning block to interpret scenes and a generation block to create physically grounded outputs. Cosmos 3 tops open leaderboards across vision reasoning, world generation, and action generation benchmarks.

**Links**: [NVIDIA Blog](https://blogs.nvidia.com/blog/cosmos-3-physical-ai-open-world-foundation-model/)

### Transaction Foundation Models for Financial Services

NVIDIA released a "Build Your Own Transaction Foundation Model" developer example. Revolut built PRAGMA — trained on 24 billion events across 26 million users — outperforming task-specific models across credit scoring, fraud detection, and recommendations. Mastercard is building its own large tabular foundation model for payments with NVIDIA, AWS, and Databricks.

**Links**: [NVIDIA Blog](https://blogs.nvidia.com/blog/financial-institutions-transaction-foundation-models/)

## Trend Watch

### The Agentic Stack is Solidifying

Three separate developments this week point to the same conclusion: the infrastructure layer for agentic AI is rapidly maturing into a coherent stack.

1. **NVIDIA + Microsoft** are building the hardware-software-cloud continuum for agents — from RTX Spark laptops to Azure AI factories, with OpenShell providing the security runtime.

2. **Anthropic's coding agents research** shows 20% adoption among social scientists, with Claude Code as the dominant tool. The productivity gains are real but concentrated in early pipeline work — the "last mile" of journal submission hasn't been affected yet.

3. **NVIDIA's Jetson + FOX + Cosmos 3** announcements push agents into the physical world — factories, robots, traffic systems, and smart cities. The edge agent is becoming a real product category.

The common thread: 2026 is the year agentic AI moves from demos to deployment infrastructure. The companies building the deployment layer (NVIDIA, Microsoft, Anthropic) are positioning for a multi-year platform shift.
