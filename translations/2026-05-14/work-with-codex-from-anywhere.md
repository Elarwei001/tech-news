# Codex 进入 ChatGPT 移动端，长任务 agent 协作开始脱离桌面

> 原文：https://openai.com/index/work-with-codex-from-anywhere/
>
> 说明：这是 AI News Digest 对头条一手来源的中文译文/译注版，用于补齐 2026-05-14 日报的可读中文材料。

## 正文翻译

OpenAI 宣布 Codex 进入 ChatGPT iOS 和 Android 移动端。用户可以在手机上查看活跃线程、审批命令、切换模型、看截图、终端输出、diff 和测试结果，并通过 secure relay 连接本地机器、远程开发机或受管环境。OpenAI 称 Codex 每周用户已超过 400 万。

这不是简单的移动端入口，而是 agent 工作节奏的变化。长任务 agent 经常需要人类在中间给许可、纠偏和补上下文；手机端把这些小决策从桌面解放出来，让 agent 更像持续协作对象。

从行业角度看，这条消息的重要性在于，它不是孤立的产品更新，而是 AI 公司把模型能力接入真实系统时必须面对的问题：可审计性、权限边界、部署可靠性、用户信任和长期责任。

如果未来的 AI agent 要承担更多工作，企业和个人都需要知道系统为什么这样行动、数据如何被使用、出错时如何回溯，以及哪些动作必须经过人类确认。该来源提供的价值正在于把这些抽象问题落到一个具体工程或产品方向上。
