# Work with Codex from anywhere：随时随地与 Codex 协作

> 原文：https://openai.com/index/work-with-codex-from-anywhere/
>
> 译注：根据 OpenAI 官方页面可抓取正文翻译整理。保留 Codex、secure relay、devbox 等术语。

## 正文翻译

OpenAI 宣布 Codex 已进入 ChatGPT 移动应用。用户可以在任何地方保持对工作的掌控，同时 Codex 在笔记本、开发机或远程环境中继续完成任务。

随着 agent 承担更长时间的工作，一种新的协作节奏正在出现。为了让工作持续推进，用户需要能够快速回答问题、查看 Codex 找到的内容、改变方向、批准下一步操作，或者补充新的想法。

OpenAI 表示，现在每周有超过 400 万人使用 Codex。OpenAI 观察到，许多小的中途互动非常重要：一次快速确认可以让线程继续推进，避免不必要的返工，或者帮助 Codex 获得正确上下文。移动端支持让这些互动不再受限于桌面。

Codex in ChatGPT mobile 是一个完整的移动体验。用户可以查看活跃线程、审阅 Codex 的发现、批准命令、切换模型、查看截图、终端输出、diff 和测试结果。用户还可以通过 secure relay 连接本地机器、远程 devbox 或受管环境。

这意味着 Codex 不再只是桌面开发工具，而更像一个持续运行的协作对象。用户可以在通勤、会议间隙或离开电脑时处理关键确认，让长任务不会因为一个小问题停住。

## 为什么重要

长任务 agent 的体验关键，不只是 agent 能做多少，而是人类如何在正确时刻介入。很多 coding agent 工作会卡在权限、方向、上下文或审查节点。移动端把这些节点变成可以随时处理的小决策。

这对 agent 产品形态很重要。AI 不再只是一次性回答问题，而是在后台持续推进工作；人类也不再只是发起者，而是周期性地检查、审批和纠偏。

## 译后备注

- secure relay 指安全连接本地或远程开发环境的机制。
- devbox 指远程开发环境或开发机器。
