# OpenAI 发布 GPT-5.5

*2026 年 4 月 24 日更新：GPT‑5.5 和 GPT‑5.5 Pro 现已通过 API 提供。[系统卡片](https://openai.com/index/gpt-5-5-system-card/)也已更新，描述了适用的额外安全防护措施。*

我们正在发布 GPT‑5.5——我们迄今最聪明、最直观易用的模型，也是迈向计算机新工作方式的下一步。

GPT‑5.5 能更快理解你的意图，并能承担更多工作本身。它在编写和调试代码、在线研究、数据分析、创建文档和电子表格、操作软件以及跨工具完成任务方面表现出色。你无需精心管理每一个步骤，只需将一个杂乱的多部分任务交给 GPT‑5.5，就可以相信它会自行规划、使用工具、检查工作、在模糊中导航，并持续推进。

这些提升在智能体编码、计算机操作、知识工作和早期科学研究领域尤为显著——这些领域的进步取决于跨上下文推理和持续行动的能力。GPT‑5.5 在实现这一智能飞跃的同时没有牺牲速度：更大、更强的模型通常服务速度更慢，但 GPT‑5.5 在实际服务中的逐 token 延迟与 GPT‑5.4 相当，同时在智能水平上表现大幅提升。它完成相同的 Codex 任务所需的 token 也显著减少，使其在更强大能力的同时也更加高效。

我们正在发布迄今为止最强大的一套安全防护措施配套的 GPT‑5.5，旨在减少滥用同时保留有益工作的访问权限。我们在完整的安全和预备框架中对这一模型进行了评估，与内外部红队人员合作，针对高级网络安全和生物学能力增加了专项测试，并在发布前从近 200 个受信任的早期访问合作伙伴那里收集了真实用例的反馈。

今天，GPT‑5.5 正在向 ChatGPT 和 Codex 中的 Plus、Pro、Business 和 Enterprise 用户推出，GPT‑5.5 Pro 正在向 ChatGPT 中的 Pro、Business 和 Enterprise 用户推出。API 部署需要不同的安全防护措施，我们正在与合作伙伴和客户密切合作，以确保大规模服务的安全和安保要求。我们将很快把 GPT‑5.5 和 GPT‑5.5 Pro 带到 API。

## 模型能力

OpenAI 正在构建全球性的智能体 AI 基础设施，使世界各地的人和公司都能利用 AI 完成工作。过去一年中，我们看到 AI 大幅加速了软件工程。借助 Codex 和 ChatGPT 中的 GPT‑5.5，同样的变革正开始延伸到科学研究和人们在计算机上进行的更广泛的工作中。

在这些领域中，GPT‑5.5 不仅更智能，在解决问题的方式上也更高效——通常能以更少的 token 和更少的重试达到更高质量的输出。在 Artificial Analysis 的编码指数上，GPT‑5.5 以竞争前沿编码模型一半的成本提供了最先进的智能水平。

GPT‑5.5 是我们迄今最强的智能体编码模型。在 Terminal-Bench 2.0 上（该测试评估需要规划、迭代和工具协调的复杂命令行工作流），它达到了 82.7% 的最先进准确率。在 SWE-Bench Pro 上（评估真实世界的 GitHub 问题解决），它达到 58.6%，在单次通过中端到端解决了比以往模型更多的任务。在 Expert-SWE 上（我们针对长周期编码任务的内部前沿评估，预估人类完成时间中位数为 20 小时），GPT‑5.5 同样优于 GPT‑5.4。

在所有三个评估中，GPT‑5.5 在使用更少 token 的同时提高了 GPT‑5.4 的得分。

该模型的编码优势在 Codex 中表现得尤为明显，它可以承担从实现、重构到调试、测试和验证的各种工程工作。早期测试表明，GPT‑5.5 在真实工程工作所依赖的行为上表现更佳——例如在大型系统中保持上下文、在模糊故障中推理、用工具检验假设，以及将变更贯穿到周边代码库中。

## 超越基准测试

Every 的创始人兼 CEO Dan Shipper 将 GPT‑5.5 描述为"我用过的第一个具有真正概念清晰度的编码模型"。

在发布一个应用后，他花了好几天调试一个发布后的问题，然后请了他最好的工程师之一重写系统的一部分。为了测试 GPT‑5.5，他实际上倒回了时钟：模型能否看到损坏的状态并产生与工程师最终决定相同的那种重写？GPT‑5.4 不能。GPT‑5.5 可以。

MagicPath 的 CEO Pietro Schirano 在 GPT‑5.5 将一个包含数百个前端和重构变更的分支合并到同样发生了重大变化的主分支时看到了类似的跨越，在约 20 分钟内一次性解决了问题。

测试该模型的高级工程师表示，GPT‑5.5 在推理和自主性方面明显强于 GPT‑5.4 和 Claude Opus 4.7，能够提前发现问题并在没有明确提示的情况下预测测试和审查需求。在其中一个案例中，一位工程师要求它重新架构一个协作式 Markdown 编辑器中的评论系统，回来时看到了一个几乎完成的 12 个 diff 堆栈。

NVIDIA 的一位提前使用该模型的工程师甚至说："失去 GPT‑5.5 的访问权限感觉就像我截肢了一样。"

Cursor 的联合创始人兼 CEO Michael Truell 表示："GPT-5.5 明显比 GPT-5.4 更聪明、更持久，编码性能更强，工具使用更可靠。它在显著更长的时间内不会提前停止，这对于我们的用户委托给 Cursor 的复杂、长时间运行的工作最为重要。"

NVIDIA 企业 AI 副总裁 Justin Boitano 表示："GPT-5.5 提供了执行密集型工作所需的持续性能。该模型在 NVIDIA GB200 NVL72 系统上构建和服务，使我们的团队能够从自然语言提示端到端地交付功能，将调试时间从天缩短到小时，并在复杂的代码库中将数周的实验变成一夜之间的进展。这不仅仅是更快的编码——这是一种全新的工作方式，帮助人们以一种根本不同的速度运作。"

## 科学与数学研究

GPT‑5.5 在科学和技术研究工作流程上也展现了进步——这些领域需要的不仅是回答一个难题。研究人员需要探索一个想法、收集证据、检验假设、解读结果，并决定下一步尝试什么。GPT‑5.5 在持续穿越这个循环方面比其他模型更出色。

值得注意的是，GPT‑5.5 在 [GeneBench](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) 上相比 GPT‑5.4 有了明显提升——这是一个聚焦于遗传学和定量生物学中多阶段科学数据分析的新评估。这些问题要求模型在最少监督指导下推理可能有歧义或有错误的数据，处理隐藏的混杂因素或质控失败等现实障碍，并正确实施和解读现代统计方法。该模型的表现令人瞩目——这里的任务通常对应科学专家数天的项目。

同样，在 [BixBench](https://arxiv.org/abs/2503.00096) 上——一个围绕真实世界生物信息学和数据分析设计的基准测试——GPT‑5.5 在已发布分数的模型中取得了领先表现。该模型的科学能力现在已经强大到足以作为真正的合作科学家，有意义地加速生物医学研究的前沿进展。

在另一个例子中，GPT‑5.5 的一个内部版本配合定制工具帮助发现了关于拉姆齐数（Ramsey numbers）的[新证明](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/Ramsey.pdf)，这是组合数学中的核心对象之一。组合数学研究离散对象如何组合在一起：图、网络、集合和模式。拉姆齐数大致问的是：一个网络需要多大才能保证某种秩序一定会出现。这一领域的结果稀少且通常在技术上非常困难。在这里，GPT‑5.5 发现了关于非对角拉姆齐数的一个长期渐近事实的证明，后来在 Lean 中得到了验证。这一结果是 GPT‑5.5 不仅仅贡献代码或解释，而是提供令人惊讶且有用的数学论证的一个具体例证。

Jackson 基因组医学实验室的免疫学教授兼研究员 Derya Unutmaz 使用 GPT‑5.5 Pro 分析了一个包含 62 个样本和近 28,000 个基因的基因表达数据集，生成了一份详细的研究报告，不仅总结了发现，还提出了关键问题和洞见——他说这项工作本需要他的团队数月时间。

波兹南亚当·密茨凯维奇大学数学助理教授 Bartosz Naskręcki 使用 Codex 中的 GPT‑5.5 在 11 分钟内从单个提示构建了一个代数几何应用，可视化了二次曲面的交点和曲线。
