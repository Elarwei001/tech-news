# 扩展 Project Glasswing（中文翻译）

*原文：[Expanding Project Glasswing](https://www.anthropic.com/news/expanding-project-glasswing) | 翻译日期：2026-06-10 | AI 译*

---

[Project Glasswing](https://www.anthropic.com/glasswing) 是我们保护世界最重要软件的合作努力。4 月初，我们宣布约 50 个初始合作伙伴获得了 Claude Mythos Preview 的访问权限，此后，他们一直在部署该模型扫描其代码库以发现漏洞。我们最近描述了这些合作伙伴迄今为止如何发现了超过 10,000 个高严重性或关键安全漏洞。

现在我们正在扩展 Project Glasswing。在与 Project Glasswing 合作伙伴、安全行业、开源软件维护者以及美国政府进行数周密切合作后，我们将合作伙伴关系扩展到约 150 个新组织。每个组织都需要在获得访问权限之前满足我们的安全要求。

这个新组中的组织分布在 15 个以上的国家，大多数为更多国家提供关键基础设施。（未来，我们打算进一步扩大地理覆盖范围。）该组涵盖了在初始批次中代表性不足的几个行业，如电力、水务、医疗、通信和硬件。许多新合作伙伴是供应商——维护着全球许多其他组织（包括政府）依赖的代码库的公司或非营利组织。

每个合作伙伴的共同点是，对其代码库的成功攻击可能是灾难性的。对于大多数合作伙伴，我们估计重大攻击可能影响超过 1 亿人，对全球和国家安全产生重要影响。

这次扩展是我们迈向长期目标的下一步：让 AI 使所有软件更安全，帮助我们行业适应 AI 可能如何改变网络安全的核心假设。

## Project Glasswing 的角色

Project Glasswing 和 Claude Mythos Preview 的能力在软件行业内部和政府间引发了广泛讨论——关于 AI 如何改变网络安全。这些讨论影响了我们如何扩展该计划，也塑造了我们对 Project Glasswing 根本目的的思考。

廉价、快速的强大网络 AI 模型即将到来。我们希望 Project Glasswing 推动机构采取反映这一现实的运营规范。

Mythos Preview 延续了我们一段时间以来一直警告的长期趋势：我们预计在 6 到 12 个月内，许多其他 AI 公司将拥有 Mythos 级模型，他们可能在没有安全防护措施的情况下发布这些模型。在那个世界中，网络攻击可能更加频繁，形式也更加不可预测。网络防御者必须适应以保持同步。

我们认为我们的角色是双重的。首先，通过安全地提供更好的模型、工具和公共基础设施的广泛访问，帮助软件行业适应。其次，稳步转变我们提供的支持——从发现漏洞到披露、修复和部署已修补的软件。

### 支持网络防御者

到目前为止，公司、非营利组织、维护者和研究人员行动迅速。在 Project Glasswing 的最初几周内，每个成员都开始大规模使用 Mythos Preview，与其他合作伙伴分享信息和最佳实践，并与第三方合作对模型的发现进行分类。这些组织适应新工具的方法可以而且应该在整个数百万面临网络攻击风险的组织和开发者中广泛复制。

为支持这一点，我们最近发布了 [Claude Security](https://claude.com/product/claude-security)，这是一款使用我们最新的公共前沿模型（如 Claude Opus 4.8）扫描代码库并建议补丁的产品。我们还应可信安全团队的要求，发布了我们开发的工具，帮助 Project Glasswing 合作伙伴更快地发现漏洞。

我们打算走得更远：我们的长期目标是支持行业创建强大网络模型时代的新举措、标准和基础设施。

### 加速修补和安全的其余环节

正如我们此前讨论的，网络安全的瓶颈现在是验证、披露和修补 Mythos 级模型能够发现的大量漏洞。

Mythos Preview 本身可以提供帮助。Project Glasswing 的许多合作伙伴现在使用该模型编写补丁，以及进行防止漏洞首先出现的预发布检查。像 Mythos Preview 这样的模型还可用于渗透测试（模拟网络攻击以识别漏洞可能被利用的方式）、自动化威胁检测和响应、以及以内存安全语言重建遗留代码库等许多防御任务。

我们正在与第三方讨论如何大幅扩大开源软件中漏洞的审查和修补规模。我们还在分享向开源维护者披露漏洞的想法和最佳实践，旨在使这些报告更容易分类和处理。

## 前进之路

为应对这一即将到来的挑战的规模，可能需要数十万个组织、研究人员和维护者获得对最先进网络能力和工具的访问。

我们正在尽快安全地向通用访问发布 Mythos 级能力。为此，我们需要高度强大的安全防护措施，防止模型的网络能力被滥用——这些安全防护是我们（据我们所知也是所有其他 AI 开发者）尚未开发出来的。因为网络安全既有有益的用途也有破坏性的用途，使安全防护既足够强大又足够精确是一项重大挑战。

在此期间，我们计划进一步扩展 Project Glasswing——优先考虑额外的关键基础设施提供商、关键开源软件维护者和安全测试人员。我们打算让未来的扩展覆盖美国和海外的组织，就像这次一样。我们还打算扩大我们的网络验证计划，该计划将为更多组织授予 Mythos 级能力用于特定的网络防御任务。

未来，前沿模型发布将变得越来越高风险。能力将继续在所有领域提升，包括许多像网络安全一样既能赋予攻击者也能赋予防御者力量的领域。这不会是我们最后一次需要面对这样的挑战。但 Project Glasswing 教会了我们很多关于如何在模型跨越重要能力阈值时做出响应。如果我们成功，我们希望能够为防御者建立永久优势。
