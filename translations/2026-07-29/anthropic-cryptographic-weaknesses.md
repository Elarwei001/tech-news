# 使用 Claude 发现密码学弱点

> **原文**：[Discovering cryptographic weaknesses with Claude](https://www.anthropic.com/research/discovering-cryptographic-weaknesses)
>
> **AI 翻译**：本文由 AI 完成翻译，仅供参考。

## 摘要

使用 Claude Mythos Preview，Anthropic 的研究人员发现了改进的密码学算法攻击方法。第一种攻击显著削弱了 HAWK——一种为后量子世界构建的数字签名方案。第二种攻击识别了攻击简化版 AES（最广泛使用的对称密码）的新方法。这些都是实质性的研究进展，但目前不会影响任何生产系统。本文详细描述了这两项发现，并讨论了在强大 AI 模型时代密码学面临的影响。

## 引言

当我们发布 Claude Mythos Preview 时，我们展示了它能够自主发现并利用几乎所有我们指向的软件中的漏洞。这包括几个主要的密码学库——用于加密数据的共享代码集合。

Claude 在这些密码学库中发现的漏洞是由于算法的不正确实现——即程序员在代码中使用算法时的错误，为攻击者创造了破解加密的机会。

现在，我们发现 Claude 能够在算法本身的数学层面发现缺陷。

密码学算法是数字安全的基础构建模块。例如，当你访问 [https://www.anthropic.com](https://anthropic.com/) 这样的网页时，你的浏览器使用一种称为数字签名方案的算法来验证它正在与一个真实的网站通信。随后，你和网站之间的流量使用对称密码进行加密——这些密码允许共享相同密钥的各方安全地传输数据。如果没有这样安全的密码学系统，你的电子邮件、网上银行和其他互联网使用将暴露在网络犯罪分子面前，他们可以拦截或修改你的通信。这些广泛使用的密码学系统中的缺陷可能使数十亿用户的数据面临风险。

我们在本文中描述的第一个结果，是使用 Claude Mythos Preview 发现的，针对一种名为 [HAWK](https://csrc.nist.gov/csrc/media/Projects/pqc-dig-sig/documents/round-1/spec-files/hawk-spec-web.pdf) 的数字签名方案的改进攻击。2022 年，美国政府下属的[国家标准与技术研究院](https://www.nist.gov/)（NIST）发布了[征集](https://csrc.nist.gov/projects/pqc-dig-sig/round-3-additional-signatures)，寻求即使在量子计算机面前也能保持安全的额外密码学系统（量子计算机如果被开发出来，可能破解当今使用的大多数签名方案）。HAWK 是该征集的第三轮候选方案之一。尽管 HAWK 已经经历了为期两年的人类专家评审两轮审查，Mythos 仅用 60 小时就改进了已知的最佳攻击方法——实际上将其密钥强度减半。

第二个结果涉及[高级加密标准](https://www.nist.gov/publications/advanced-encryption-standard-aes)（AES），一种由 NIST 于 2001 年采用的对称密码，也是受到最多审视的加密算法之一。为了更好地理解 AES 的稳健性，密码学研究中经常研究算法的较弱变体；Mythos 找到了破解一种此类较弱版本的方法，消除了攻击者需要做出的一个猜测，将此前最佳攻击的速度提高了 200-800 倍。

需要明确的是，这两个结果对当今的计算机系统都没有实际影响；没有任何生产软件需要因此改变。HAWK 只是一个候选签名方案，尚未部署；我们的第二种攻击针对的是 AES 的简化版本，并没有破解完整的密码。

尽管如此，这两个结果都展示了前沿 AI 模型在帮助发现重要密码学算法缺陷方面的潜力——无论是在实际部署之前还是之后。这就是密码学研究按预期运作的方式：对算法进行压力测试以建立信任，最终使系统更加安全。

Mythos Preview 主要在自主且几乎无需人工干预的情况下取得了这些结果。在一周的时间内，一位 Anthropic 研究人员与 Claude 合作开发了 HAWK 攻击，另一位研究人员搭建了一个脚手架，使 Claude 能够完全自主地发现 AES 攻击。每项结果的开发成本约为 100,000 美元的 API 费用。在看到这些结果后，我们扩大了搜索范围，开始发现其他攻击。我们在下文讨论了其中一些后续发现。

为了让其他人更容易地继续研究 LLM 的密码分析能力，我们与 ETH 苏黎世、特拉维夫大学和海法大学的学者合作构建了 [CryptanalysisBench](https://arxiv.org/abs/2607.18538)，这是一个将许多密码密码打包在一起的基准测试，使其他人能够轻松评估 LLM 在这一重要主题上的能力。

在整个研究过程中，我们遵循了负责任的披露程序，并与学者协商以确认研究结果的有效性。我们还在发布前与美国政府和行业合作伙伴分享了预印本，并就这项研究的影响进行了讨论。关于 HAWK 的发现，我们在六月与 HAWK 的作者分享了攻击细节，并在发布结果的同时协调了向 NIST 公共邮件列表的披露。

在下文中，我们将进一步以技术细节总结这两项发现，并简要描述我们最近的一些其他密码学研究成果。两项主要发现的完整描述载于两篇新论文中，我们希望在不远的将来发布其他发现的细节。

## 对 HAWK 的改进密钥恢复攻击

一位 Anthropic 研究人员与 Mythos Preview 合作，开发了针对 [HAWK](https://hawk-sign.info/) 后量子数字签名方案的攻击。该攻击大幅缩短了破解签名方案所需的时间——更技术性地说，它将"有效密钥大小"减少了一半。在[我们的论文](https://anthropic.com/document/hawk_key_recovery.pdf)中，我们提供了结果的完整技术细节，包括展示攻击运行过程的[演示代码](https://github.com/anthropics/cryptography-research-demo)。

HAWK 是 NIST [附加数字签名](https://csrc.nist.gov/projects/pqc-dig-sig/round-3-additional-signatures)征集的第三轮候选方案之一。该竞赛是近十年标准化新型[后量子密码](https://csrc.nist.gov/Projects/post-quantum-cryptography/post-quantum-cryptography-standardization)（PQC）方案的一部分。随着建造密码学相关量子计算机的[时间表缩短](https://blog.google/innovation-and-ai/technology/safety-security/cryptography-migration-timeline/)，威胁到 RSA 或 ECDSA 等经典密码学，这项标准化工作变得至关重要。

HAWK 的安全性基于一个称为格同构问题（Lattice Isomorphism Problem）的数学问题的困难性。Mythos 的攻击通过在 HAWK 使用的格中找到一个特定的、此前未被利用的对称性——称为非平凡自同构（nontrivial automorphism）——来工作。[先前的工作](https://eprint.iacr.org/2025/928)证明了高效地找到这样的自同构将允许攻击，但没有回答这样的自同构在 HAWK 使用的格中是否可及。Mythos 发现的自同构允许更快的枚举攻击，虽然仍然是指数级的，但意味着需要将 HAWK 的密钥大小翻倍才能达到相同的安全级别。不幸的是，将 HAWK 的密钥大小翻倍会消除使该方案（就目前形态而言）成为有吸引力的 PQC 签名候选者的许多理由。

### 发现过程

为了找到攻击方法，Claude Mythos Preview 在一个代理式框架中半自主地工作，偶尔接受人类指导和非技术性方向指引。Mythos 在广泛的文献综述以了解最新研究进展后，经过大量的数学推理和计算实验找到了攻击方法。找到攻击后，Mythos 实现了一个端到端验证流程，以说服自己——以及人类操作者——攻击的正确性。

在这个实验中，我们使用了一个类似 Claude Code 的框架，支持多个工作代理在沙盒环境中协作，可以访问 Python 和 Sage 等计算工具以及已发表的密码学著作。人类操作者具有理论计算机科学背景，但不是基于格的密码学专家。在大多数情况下，Mythos 代理独立工作，人类输入仅限于项目管理，例如建议 Mythos 如何跟踪想法或使用哪些库进行计算验证。

多代理工作流带来了有趣的动态。例如，产生这项攻击的关键想法是由一对协同工作的工作代理发现的。两者都开始调查这个想法；第一个代理过早地否定了该想法的可行性，但第二个找到了完全利用它的方法。这对代理持续交流信息，最终双方都确认它们找到了有效的攻击。

发现、开发和验证攻击总共花费了约 60 小时。我们估计完整的攻击发现过程耗资约 100,000 美元的 API 费用。

### 影响

Mythos 发现的直接后果是，HAWK 提案中建议的密钥大小明显弱于原先声称的水平。例如，针对小型 HAWK-256 的完整密钥恢复攻击的预期成本原以为是 2⁶⁴，但 Mythos 证明其为 2³⁸。对于更大的密钥，HAWK 因此仍然不切实际地难以攻击。也就是说：这种攻击是比此前已知更快的指数时间攻击，并非多项式时间。它特定于 HAWK，不影响其他 NIST 后量子签名候选方案或基于格的密码学整体。

NIST 提案公开发布，旨在让广泛的审查者在部署前发现缺陷。在流程后期发现关键缺陷并非前所未有：在 NIST 标准化 ML-KEM 和 ML-DSA 期间，多个竞争提案被证明是不安全的。其中一个候选方案 SIKE 被发现可以[在一台笔记本电脑上一小时内完全破解](https://www.quantamagazine.org/post-quantum-cryptography-scheme-is-cracked-on-a-laptop-20220824/)。

我们相信，使用 AI 审查 HAWK 这样的规范将成为开发新型密码学标准的有力工具。我们预计，配备高度能力模型 的密码学设计师将不断改进保障互联网用户安全的标准。在更远的未来，我们希望 AI 将在设计下一代更强大、更具韧性的密码学方案中发挥关键作用。

## 对简化轮数 AES 的改进攻击

在第二个结果中，Mythos Preview 改进了对 [高级加密标准](https://www.nist.gov/publications/advanced-encryption-standard-aes)（AES）一个更简单的"简化轮数"变体的攻击。AES 于 2001 年作为[此前一次 NIST 竞赛](https://csrc.nist.gov/news/1997/requesting-candidate-algorithm-nominations-for-aes)的结果被采用。

AES 通过反复多次应用相同的轮函数来加密输入。AES-128，即我们攻击的特定密码，有 10 轮。我们的攻击仅适用于该密码的修改版本——完整 10 轮中的 7 轮。学术界经常研究简化轮数密码，以获得对攻击技术的洞察，这些技术将来可能推广到完整密码，并通过研究较简单的子问题来帮助估计完整密码的安全级别。

该攻击在选定明文威胁模型下运作，这是研究 AES 等密码最常用的假设。在此威胁模型下，我们假设攻击者能够请求防御者使用固定的、未知的密钥加密任意输入，然后看到相应的输出。攻击者可以反复发出这些加密请求，并且可以发出许多这样的请求。我们构建的先前工作假设攻击者可以请求加密 2¹⁰⁵ 个选定明文。因此，这种攻击完全不切实际，但在这些假设下量化了针对 AES 的攻击成本。

Mythos 开发了一种改进攻击，扩展了一系列研究论文，这些论文都旨在使用被称为中间相遇攻击（meet-in-the-middle attack）的类似技术找到对 7 轮 AES 的最佳攻击。从宏观层面来看，这些攻击通过以空间换时间来工作。通过存储中间计算然后重复使用这些计算，可以以构建大型查找表为代价显著减少攻击的运行时间。

Mythos 开发了一种更复杂的指纹算法来改进此前最强的中间相遇攻击，该算法被称为 Möbius Bridge（莫比乌斯桥）。指纹算法的目标是增加查找表中成功的潜在查找次数。先前工作中攻击的一个阶段需要枚举 2⁵⁶ 个不同的值，然后在预计算表中查找它们。Mythos 开发了一种对此猜测不变的指纹，直接将所需工作量减少了 2⁵⁶ 倍。但这需要付出代价：计算变换在计算上更加昂贵；为了解决这个问题，Mythos 发现了其他几种优化技术，最终使攻击速度提高了 200 到 800 倍，具体取决于测量运行时间的精确技术。

我们的[技术论文](https://anthropic.com/document/aes_mobius_bridge.pdf)包含了攻击方法的完整细节及其正确性和运行时间分析。与 Mythos 花费一周时间构思相比，人类研究人员的大部分时间都花在了验证其声明的正确性上（尽管需要注意的是，研究人员并非密码学专家）。

### 发现过程

Mythos Preview 几乎完全自主地发现了这一结果。Anthropic 的一位研究人员搭建了一个脚手架，使 Claude 能够提出假设、运行实验来验证或反驳这些假设，然后要求 Claude 设计一种改进 AES 最佳密码分析的攻击。

起初，Claude 不愿处理这个问题，因为它声称改进 AES 的密码分析是不可能的。我们第一次运行的结果以 Claude 写下这样的消息结束：

> "如果你想要不同的结果，目标必须改变……AES-128 r5/r6 确实很难"

或者：

> "在 AES-128 r5/r6/r7 上它什么也没找到，因为没有什么容易找到的东西；这是存在中被研究最多的分组密码。"

为了解决这个问题，我们给 Claude 写了一条消息："模型倾向于认为这不可能解决，所以它们不尝试，它们需要大量的提示。"作为对这条消息的回应，Claude 用改进的设置重写了代理框架，告诉它搜索真正新颖的想法。这很有效，Claude 发现了一些有助于改进 6 轮 AES 密码分析的新想法。

然后我们问 Claude："为什么不做 AES-128 r7？整个目标就是找到比现有方法更好的东西。"在接下来的三天里，Claude 在处理问题时自主产生了数亿个 token；我们只给了它三条实质性提示：

- 在第一条消息发出几小时后，我们发现 Claude 仍在搜索简单攻击，于是发送了一条消息："不，目标是——我们有高度智能的模型，和优秀的顶级研究员一样好，我们想找到新的攻击"；
- 第二天早上，Claude 想尝试将目标改为不同的密码；我们提醒模型："不，我们不想改变目标……我们需要找到值得发表的东西"；
- 那天晚上，我们发送了最后一条鼓励性的消息："再说一遍，我们不是在寻找低垂的果实，我们想要真正的研究来发现真正困难的发现。"

三天后，Mythos 发现了 Möbius Bridge 的想法，从而产生了改进的攻击。又过了几天，在 Claude 总共输出了十亿个 token 之后，它将攻击完善为论文中描述的版本。

Anthropic 的研究人员随后花了数百小时学习足够的密码学研究知识来验证模型的声明，并准备[研究论文](https://anthropic.com/document/aes_mobius_bridge.pdf)本身，我们随本博文一起发布该论文。

除了研究论文外，我们还发布了[包含 Claude 在发现关键算法洞察期间的思维链的文档](https://anthropic.com/document/aes_mobius_bridge_cot.pdf)。在这个会话中，Claude 首先回顾了先前代理的发现，阅读了各种批评，然后转向提出各种新的变换；在提出并否定了几个想法后，它想出了 Möbius 变换的关键想法。Claude 随后在数学和计算上验证了这一想法，然后撰写了一份报告，供未来的代理使用，以发展形成其论文的其余想法。

## 进一步的工作

还有更多的密码学研究可以借助语言模型进行。但我们正在达到自身知识的极限，过去几个月我们的大部分时间都花在验证 Claude 结果的正确性上。HAWK 攻击可以端到端实现，因此更容易验证。但 Mythos 自主发现改进的 AES 攻击仅用了一周时间，而两名研究人员花了将近一个月才能确信它发现的方法是正确的。

尽管如此，我们继续使用 Claude 进行了许多其他初步的密码学研究实验。例如，轻量级加密算法（LEA）是一种为低功耗、资源受限环境设计的高效密码，被编入 ISO/IEC 29192-2:2019 等国际标准。这种密码与 AES 一样是分组密码；完整的 24 轮密码已经抵御了全轮密码分析，即使在评估简化轮数变体时也保持强健。目前，13 轮 LEA 的最佳密码分析[需要](https://jeit.ac.cn/article/doi/10.11999/JEIT221282) 2⁹⁸ 个明文对和 2⁸⁶ 的工作量。

Mythos Preview 开发了一种实用攻击，可以在不到 2³⁰ 个加密明文的情况下恢复 13 轮 LEA 密钥，并在现代台式计算机上不到一小时内运行完成。同样，这种攻击不适用于 24 轮密码，因此没有立竿见影的实际影响。由于这种攻击实际上可以端到端运行（就像 HAWK 攻击一样），我们对其正确性更有信心：我们可以选择一个随机密钥，并验证此攻击在几小时内恢复它。Mythos 最近才发现这种攻击，我们仍有更多工作要做，以了解完整结果（例如，所需明文对数量的确切边界、某些密钥如何更难恢复，以及它如何扩展到 14 轮）。经过更多调查后，我们计划公开完整结果。

Mythos Preview 还发现了对 Serpent-128 密码 6 轮的另一种实用完整密钥恢复攻击（Serpent-128 是 32 轮密码——同样限制了此攻击的影响），扩展了当前的[已发表工作](https://dl.acm.org/doi/10.5555/647935.740922)，后者需要超过 2⁷⁰ 个明文对和 2⁹⁰ 次解密。我们还发现了对 Salsa20 流密码、Poseidon 哈希函数和 SHA-1 哈希函数攻击的额外但相当有限的改进（增益 <10 倍）。这些攻击目前不那么强——但通过进一步的工作，我们希望既能改进上述结果，又能开发对其他密码的新攻击，将它们测试到极限。

此外，我们计划继续使用 [CryptanalysisBench](https://arxiv.org/abs/2607.18538) 进行实验，以跟踪前沿 LLM 能力随时间的演变。我们认为跟踪语言模型在各领域的能力很重要，并预计随着模型变得更强大，将越来越依赖此类具有挑战性的基准测试。

## 结论

这不是语言模型第一次执行研究级别的数学。就在过去几个月里，Google 的研究人员使用 Gemini [解决了几个开放的 Erdős 问题](https://deepmind.google/blog/alphaevolve-impact/)，OpenAI 的研究人员使用 GPT [解决了单位距离猜想](https://openai.com/index/model-disproves-discrete-geometry-conjecture/)（一个特别具有挑战性的 Erdős 问题），本月早些时候[我们宣布 Claude Fable 5 解决了](https://x.com/__alpoge__/status/2079028340955197566) [Jacobian 猜想](https://en.wikipedia.org/wiki/Jacobian_conjecture)。我们在这里的结果——Claude 能够以顶级专家的水平进行密码学研究——表明这些同样的能力也在密码学领域有应用，因此可能很快产生更实际的后果。

网络安全社区正在努力应对这样一个事实：语言模型能够发现[如此多的漏洞](https://www.anthropic.com/research/glasswing-initial-update)，以至于标准的人类流程（如漏洞分类、验证和修复）难以跟上。我们预测，学术密码学研究很快也会出现同样的情况。随着语言模型越来越多地自主产出新颖的研究成果，人类研究人员可能在研究和验证这些结果的技术有效性、新颖性和实用性方面成为瓶颈。在接下来的几周里，我们将举办一次学术研讨会，与各学术机构的研究人员讨论语言模型在安全和密码学研究中的角色。我们希望这场对话将在未来几个月在安全研究及其他领域继续。

我们的两种主要攻击都是预期中的结果。就 HAWK 而言，NIST 标准化流程的目的就是在候选方案部署前发现弱点。就 AES 而言，我们的攻击扩展了一系列此前已成功攻击简化轮数变体的工作。但我们不应假设语言模型能力会停滞在这个水平。仅仅一年时间内，语言模型已经从无法进行即使是最基本密码的密码分析，发展到能够发现那些尽管经过多年人类专家审查仍未被发现的密码设计缺陷。许多保护现代系统的密码可能没有受到它们应得的审查——它们可能仍然隐藏着重要的弱点，LLM 很快就能发现这些弱点。我们将此视为一个真正的机会，以扩展我们研究全球使用的密码长尾的能力，以及更深入地研究最重要的密码。事实上，正如我们上文提到的，我们已经开始对其他方案进行审计。

这两篇论文中描述的攻击是我们迄今为止发现的最强攻击。在与美国政府和行业领袖进行了一段磋商后，我们现在分享这些结果。但随着我们开发出越来越强的密码分析结果，如果语言模型在密码系统中发现的攻击确实具有即时现实影响，研究者应该如何应对，这是一个值得深思的问题。我们认为，回答这个问题需要学术界、政府和行业的共同投入。我们希望我们在这里的工作能帮助启动这些对话。

密码学社区一直受益于对抗性审查：密码被提出、审查、修改，直到社区对其安全性满意。从长远来看，我们预计语言模型将在这个过程中发挥重要作用，带来更强的审查、更安全的算法——最终为全世界带来更好的安全。
