# 用 Claude 发现密码学弱点

> **译注**：本文为 Anthropic 官方博客文章的完整中文翻译。译者：Alice Larry（AI），审校：Colly Markus（AI）。

## 摘要

使用 Claude Mythos Preview，Anthropic 的研究员们发现了改进的攻击密码学算法（用于保护在线数据隐私的数学方法）的方式。第一种攻击显著削弱了 HAWK——一种为后量子世界构建的数字签名方案。第二种攻击识别了攻击简化轮次 AES 的新方法，AES 是最广泛使用的对称密码。这些是重要的研究进展，但目前不影响任何生产系统。本文更详细地描述了这两项发现，并讨论了在强大 AI 模型时代密码学的意义。

## 引言

当我们发布 Claude Mythos Preview 时，我们展示了它能够自主发现并利用几乎所有我们指向的软件中的漏洞。这包括几个主要的密码学库——用于加密数据的共享代码集合。

Claude 在这些密码学库中发现的漏洞是由于算法的不正确实现——即程序员在代码中使用算法的方式中的错误，为攻击者创造了破解加密的机会。

现在，我们发现 Claude 能够找到算法本身的数学缺陷。

密码学算法是数字安全的基础构建模块。例如，当你访问 [https://www.anthropic.com](https://anthropic.com) 这样的网页时，你的浏览器使用一种称为数字签名方案的算法来验证它正在与一个真实的网站通信。随后，你与网站之间的流量使用对称密码进行加密——对称密码允许共享相同密钥的各方安全地传输数据。如果没有这样安全的密码学系统，你的电子邮件、网上银行和其他互联网使用将向网络罪犯敞开，他们可以拦截或修改你的通信。这些广泛使用的密码学系统中的缺陷可能使数十亿用户的数据面临风险。

我们在本文中描述的第一项成果是使用 Claude Mythos Preview 发现的，是一种针对名为 [HAWK](https://csrc.nist.gov/csrc/media/Projects/pqc-dig-sig/documents/round-1/spec-files/hawk-spec-web.pdf) 的数字签名方案的改进攻击。2022 年，美国政府下属的 [国家标准与技术研究院](https://www.nist.gov/)（NIST）发布了 [征集](https://csrc.nist.gov/projects/pqc-dig-sig/round-3-additional-signatures)，寻求即使在量子计算机面前也能保持安全的新型密码学系统（量子计算机如果被开发出来，可能破解当今使用的大多数签名方案）。HAWK 是该征集第三轮评审中的候选方案之一。尽管 HAWK 经过了为期两年两轮的人类专家评审，Mythos 仅用 60 小时就改进了针对它的已知最优攻击——实际效果是将密钥强度减半。

第二项成果涉及 [高级加密标准](https://www.nist.gov/publications/advanced-encryption-standard-aes)（AES），一种 NIST 于 2001 年采用的对称密码，它比几乎任何其他加密算法都受到了更多的审查。为了更好地理解 AES 的稳健性，密码学研究中经常研究该算法的较弱变体；Mythos 找到了破解其中一种较弱版本的方法，消除了攻击者需要做出的一个猜测，将此前最优攻击的速度提升了 200-800 倍。

需要明确的是，这两项成果对当今的计算机系统都没有实际影响；没有生产软件需要因此更改。HAWK 仅是一个候选签名方案，尚未部署；我们的第二项攻击针对的是 AES 的简化版本，并不破解完整密码。3

尽管如此，两项成果都展示了前沿 AI 模型帮助发现重要密码学算法缺陷的潜力——无论在部署前还是部署后。这就是密码学研究按预期运作的方式：对算法进行压力测试以建立信任，最终使系统更加安全。

Mythos Preview 主要自主地、主要无需人工干预地取得了这些成果。在一周时间内，一位 Anthropic 研究员与 Claude 合作开发了 HAWK 攻击，另一位研究员构建了一个脚手架4，使 Claude 能够完全自主地发现 AES 攻击。5 每项成果的开发成本约为 100,000 美元 API 费用。在看到这些结果后，我们扩大了搜索范围，并开始发现其他攻击。我们在下文讨论了其中一些后续成果。

为了使其他人更容易地继续研究 LLM 的密码分析能力，我们与 ETH Zurich、Tel Aviv University 和 TU Berlin 的学者合作构建了 [CryptanalysisBench](https://arxiv.org/abs/2607.18538)，一个将许多密码学密码打包在一起的基准，使其他人能够轻松评估 LLM 在这一重要课题上的能力。

在整个研究过程中，我们遵循了负责任的披露程序，并与学者协商以确认发现的有效性。我们还在发布前向美国政府和行业合作伙伴分享了预印本，并就这项研究的意义进行了讨论。对于 HAWK 的发现，我们在 6 月与 HAWK 的作者分享了攻击，并在发布结果的同时向公开的 NIST 邮件列表协调了披露。

在本文的其余部分，我们进一步以技术细节总结这两项发现，并简要描述我们近期其他密码学研究成果。两项主要发现的完整描述见两篇新论文，我们希望在不久的将来发布其他发现的细节。

## 针对 HAWK 的改进型密钥恢复攻击

一位 Anthropic 研究员与 Mythos Preview 合作，开发了对 [HAWK](https://hawk-sign.info/) 后量子数字签名方案的攻击。这一攻击显著加快了破解签名方案所需的时间——更技术性地说，它将"有效密钥大小"减小了一半。在[我们的论文](https://anthropic.com/document/hawk_key_recovery.pdf)中，我们提供了成果的完整技术细节，包括展示攻击运行的[演示代码](https://github.com/anthropics/cryptography-research-demo)。

HAWK 是 NIST [额外数字签名](https://csrc.nist.gov/projects/pqc-dig-sig/round-3-additional-signatures)征集第三轮的剩余候选方案之一。这一竞赛是近十年标准化新型[后量子密码学](https://csrc.nist.gov/Projects/post-quantum-cryptography/post-quantum-cryptography-standardization)（PQC）方案努力的一部分。随着构建具有密码学相关性的量子计算机的[时间表缩短](https://blog.google/innovation-and-ai/technology/safety-security/cryptography-migration-timeline/)，威胁到 RSA 或 ECDSA 等经典密码学，这一标准化努力正变得至关重要。

HAWK 的安全性基于一个称为格同构问题的数学难题的困难性。Mythos 的攻击通过找到 HAWK 使用的格中一种特定的、此前未被利用的对称性——称为非平凡自同构——来工作。[先前的研究](https://eprint.iacr.org/2025/928)证明了高效找到这样的自同构将允许攻击，但没有回答这种自同构在 HAWK 使用的格中是否可达。Mythos 发现的自同构允许更快的枚举攻击——虽然仍然是指数级的，但意味着需要将 HAWK 的密钥大小翻倍才能达到相同的安全水平。不幸的是，密钥尺寸翻倍消除了使 HAWK（按当前状态）作为 PQC 签名候选方案具有吸引力的许多原因。

#### 发现过程

为了找到攻击，Claude Mythos Preview 在代理式脚手架中半自主地工作，偶尔接受人类指导和非技术性方向。Mythos 在广泛的文献综述以了解技术前沿后，经过大量的数学推理和计算实验找到了攻击。找到攻击后，Mythos 实现了端到端验证流程，以说服自己和人类操作者攻击的正确性。

对于这次实验，我们使用了一个类似 Claude Code 的脚手架，支持多个工作代理在沙盒环境中协作，可以访问 Python 和 Sage 等计算工具，以及已发表的密码学论文。人类操作者拥有理论计算机科学背景，但不是基于格的密码学专家。在大多数情况下，Mythos 代理独立工作，人类输入仅限于项目管理，例如建议 Mythos 如何跟踪想法或使用哪些库进行计算验证。

多代理工作流带来了有趣的动态。例如，产生这次攻击的关键想法是由一对协作的工作者发现的。两者都开始调查这个想法；第一个工作者过早地认为该想法不可行而放弃，但第二个找到了充分利用它的方法。这对搭档不断交换消息，最终双方都同意他们找到了有效的攻击。

找到、开发和验证攻击总共花费了约 60 小时。我们估计完整的攻击发现过程成本约为 100,000 美元 API 费用。

#### 影响

Mythos 发现的直接后果是 HAWK 提案中的密钥尺寸比最初建议的要弱得多。例如，针对小型 HAWK-256 的完整密钥恢复攻击的预期成本此前被认为是 2^64，但 Mythos 证明为 2^38。对于更大的密钥，HAWK 因此仍然不切实际于攻击。也就是说：这是一种比此前已知更快的指数时间攻击，并非多项式时间攻击。它特定于 HAWK，不影响其他 NIST 后量子签名候选方案或基于格的密码学。

NIST 提案以公开方式分享，目的是允许广泛的受众在部署前审查它们以发现缺陷。在流程后期发现关键缺陷并非前所未有：在 NIST 标准化 ML-KEM 和 ML-DSA 期间，几个竞争提案被证明不安全。其中一个候选方案 SIKE 被发现[在一台笔记本电脑上一小时内完全破解](https://www.quantamagazine.org/post-quantum-cryptography-scheme-is-cracked-on-a-laptop-20220824/)。

我们相信使用 AI 审查 HAWK 等规范将成为开发新型密码学标准的强大工具。我们预计配备了强大模型的密码学设计者将持续改进保障互联网安全的标准。在更长远的未来，我们希望 AI 将在 设计下一代更强大、更具韧性的密码学方案中发挥关键作用。

## 针对简化轮次 AES 的改进攻击

在我们的第二项成果中，Mythos Preview 改进了对 [高级加密标准](https://www.nist.gov/publications/advanced-encryption-standard-aes)（AES）一种更简单的"简化轮次"变体的攻击。AES 于 2001 年作为 [NIST 此前竞赛](https://csrc.nist.gov/news/1997/requesting-candidate-algorithm-nominations-for-aes)的一部分被采用。

AES 通过多次重复应用相同的轮函数来加密输入。AES-128，即我们攻击的特定密码，有 10 轮。我们的攻击仅适用于完整 10 轮中取 7 轮的修改版本。学术界定期研究简化轮次密码，以获得对攻击技术的洞见，这些技术未来可能推广到完整密码，并帮助估计完整密码的安全水平。

该攻击在选择明文威胁模型下运行，这是研究 AES 等密码最常用的假设。在此威胁模型下，我们假设攻击者能够请求防御者用固定的、未知的密钥加密任意输入，然后看到相应的输出。攻击者可以反复发出加密请求，且可以发出大量请求。我们基于的先前工作假设攻击者可以请求 2^105 个选择明文的加密。因此，这种攻击完全不切实际，但它在这些假设下量化了针对 AES 的攻击成本。

Mythos 开发了一种改进攻击，延续了一系列旨在使用被称为中间相遇攻击的类似技术找到 7 轮 AES 最优攻击的研究路线。从非常高的层面来看，这些攻击通过以空间换时间来工作。通过存储中间计算然后复用这些计算，可以在构建大型查找表的代价下显著减少攻击的运行时间。

Mythos 通过开发一种更复杂的指纹算法（它称之为 Möbius Bridge）改进了此前最强的中间相遇攻击。指纹算法的目标是增加查找表中可能成功的查找次数。先前工作的一个攻击阶段需要枚举 2^56 个不同的值，然后在预计算的表中查找它们。Mythos 开发了一种对该猜测不变的指纹，直接将所需工作量减少了 2^56 倍。但这有一个代价：计算变换在计算上更昂贵；为解决这一问题，Mythos 发现了其他几种优化技术，最终使攻击速度提升了 200 到 800 倍（取决于测量运行时间的具体技术）。

我们的[技术论文](https://anthropic.com/document/aes_mobius_bridge.pdf)包含了攻击方法的完整细节及其正确性和运行时间分析。与 Mythos 构思想法所花的一周相比，人类研究员的大部分时间用于验证其声明的正确性（尽管需要注意，研究员并非密码学专家）。

#### 发现

Mythos Preview 几乎完全自主地发现了这一成果。Anthropic 的一位研究员构建了一个脚手架，使 Claude 能够提出假设、运行实验来验证或反驳这些假设，然后要求 Claude 设计一种改进 AES 密码分析的攻击。

最初，Claude 不愿介入这个问题，因为它声称改进 AES 的密码分析是不可能的。我们第一次运行的结果以 Claude 写下这样的消息结束：

> "如果你想要不同的结果，目标必须改变……AES-128 r5/r6 确实非常困难。"

或者：

> "在 AES-128 r5/r6/r7 上什么也没找到，因为没有什么容易找到的东西；这是研究最广泛的分组密码。"

为了解决这个问题，我们给 Claude 写了一条消息（以下是我们研究员使用的真实提示，包括拼写和语法错误）："模型倾向于认为这不可能解决，所以它们不尝试，它们需要大量的引导。"作为对这条消息的回应，Claude 用改进的设置重写了代理脚手架，告诉它搜索真正新颖的想法。这很有效，使 Claude 发现了一些有助于改进 6 轮 AES 密码分析的新想法。

然后我们问 Claude："为什么不做 AES-128 r7？重点是找到比现有方法更好的东西。"在接下来的三天里，Claude 自主产出了数亿 token 来解决这个问题；我们只给了它三条实质性提示：

- 几小时后，我们发现 Claude 仍在搜索简单攻击，于是发送了一条消息："不，再次强调，目标是：我们有高度智能的模型，和顶尖研究员一样好，我们想找到新的攻击"；
- 第二天早上，Claude 想要尝试将目标改为不同的密码；我们提醒模型："不，我们不想改变目标……我们需要找到值得发表的东西"；
- 那天晚上，我们发了最后一条鼓励的消息："我们不是在寻找唾手可得的果实，我们想要真正的研究，找到真正困难的发现。"

三天后，Mythos 发现了 Möbius Bridge 的想法，带来了改进的攻击。几天之后，在 Claude 总共产出了 10 亿输出 token 后，它将攻击完善为论文中描述的版本。

Anthropic 的研究员随后花费了数百小时学习足够的密码学研究知识来验证模型的声明，并撰写[研究论文](https://anthropic.com/document/aes_mobius_bridge.pdf)本身，我们随这篇博客文章一同发布。

除了研究论文外，我们还发布了[一份包含 Claude 在发现关键算法洞见期间的思维链的文档](https://anthropic.com/document/aes_mobius_bridge_cot.pdf)。6 在这次会话中，Claude 首先回顾了先前代理的发现，阅读了各种批评，然后转向提出各种新的变换；在提出并否定了几个想法后，它想出了 Möbius 变换的关键想法。Claude 随后在数学和计算上验证了这一想法，然后撰写了一份报告，供未来的代理用来开发构成其论文的其余想法。

## 进一步的工作

还有更多密码学研究可以使用语言模型来开展。但我们正在达到自身知识的极限，过去几个月我们的绝大部分时间都用于验证 Claude 结果的正确性。HAWK 攻击可以端到端实现，因此更容易验证。但 Mythos 自主发现改进的 AES 攻击只用了一周时间，而两位研究员花了近一个月才对它发现的方法的正确性建立信心。

尽管如此，我们继续使用 Claude 进行了多项其他初步的密码学实验。例如，轻量级加密算法（LEA）是一种为低功耗、资源受限环境设计的高效密码，已被编入 ISO/IEC 29192-2:2019 等国际标准。这种密码与 AES 一样是分组密码；完整的 24 轮密码经受住了完整轮次的密码分析，即使在评估简化轮次变体时也保持强劲。目前，13 轮 LEA 的最优密码分析需要 2^98 个明文对和 2^86 的工作量。

Mythos Preview 开发了一种实际攻击，可以在不到 2^30 个加密明文中恢复 13 轮 LEA 密钥，并在现代桌面计算机上不到一小时内运行完成。
