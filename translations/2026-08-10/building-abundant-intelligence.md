# 构建丰饶智能

> 以下为 OpenAI 2026 年 7 月 31 日发布的战略文章 ["Building Abundant Intelligence"](https://openai.com/index/building-abundant-intelligence/) 的完整中文翻译。

---

AI 基础设施的价值不在于它的规模有多大。它的价值在于它所使成为可能的东西：更强大的智能，触达更多人，以更低的成本。

这就是我对"丰饶"的理解。它既根植于我们的使命——确保通用人工智能造福全人类——也根植于推动我们业务的经济引擎。

当有用智能的成本下降，更多工作就变得值得去做。当模型变得更强大，这些工作就创造更多价值。随着采用的增长，我们获得了收入、真实世界的反馈以及对需求的可见性，从而继续投资下一代研究和基础设施。

更好的智能推动更广泛的采用。更广泛的采用支持更多的投资。更多的投资改善智能和效率。这就是我们正在构建的循环。

## 丰饶的经济学

我们[近期的定价公告](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)展示了这个循环如何迅速惠及客户。昨天，我们将 GPT-5.6 Luna 的价格降低了 80%，GPT-5.6 Terra 降低了 20%。Luna 现在每百万输入 token 售价 $0.20，每百万输出 token $1.20；Terra 分别为 $2 和 $12。

对于 GPT-5.6 Sol，Fast 模式以两倍价格提供最高 2.5 倍的标准处理速度，智能水平不变。

这些不仅仅是价格表上的变更。它们扩大了变得可行的工作范围，并给客户更多灵活性来平衡智能、速度、可靠性和成本。

正确的问题不是哪个模型属于哪个任务。而是：结果需要多少智能才能达到要求的效果，智能需要多快交付，以及智能应该以什么成本来实现。这种平衡可能在同一个工作流中变化多次。

客户不会为了 token 本身而购买 token。他们希望问题得到解决、软件顺利发布、合同完成审查、科学问题得到解答。正确的衡量标准是一次成功结果的成本——包括达成目标所需的时间、重试、监督和错误。

一个更强的模型，如果能正确高效地完成工作，最终可能比一个需要反复尝试或大量人工干预的更便宜的模型更经济。反过来，当一个更低成本的模型达到同样的质量标准时，它可以极大地扩大接入。机会在于以正确的价格应用最大有用的智能。

## 从每一单位算力中获取更多

交付这种价值需要的不仅是建设更多的数据中心。它需要让每一单位算力更有生产力。

我们[近期的工程工作](https://openai.com/index/gpt-5-6-frontier-intelligence-efficiency/)展示了它的样子。与技术团队合作，GPT-5.6 Sol 帮助优化了用于提供模型服务的生产软件，将端到端服务成本降低了 20%。它还帮助改进了投机解码，将 token 生成效率提高了 15% 以上。

同样重要的是，效率并非仅由模型决定。围绕它的系统同样重要。更好的路由让硬件保持高利用率。更智能的上下文管理防止智能体重复工作。更强大的工具和产品设计减少了完成任务所需的步骤。

在[近期的基准分析](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)中，保留推理和上下文管理的改进将 GPT-5.6 Sol 在公开 ARC-AGI-3 任务集上的得分从 13.3% 提高到了 38.3%，同时使用的输出 token 减少了六倍。模型没有变。围绕它的系统变了。

这些收益是复合的。更强大的模型帮助我们的团队发现新的效率。这些效率降低了服务客户的成本，扩大了用同样基础设施可以支持的工作范围。这反过来使下一代智能更加触手可及。

## 为什么全栈很重要

跨越基础设施、模型、平台和产品进行构建的优势不仅仅是我们参与了每一层。而是每一层都让其他层变得更好。

真实世界的产品使用向我们展示了客户在哪里发现价值、在哪里遇到摩擦。这种反馈帮助塑造我们的研究。研究的改进强化了我们的产品并降低了服务成本。来自 ChatGPT、ChatGPT Work、Codex 和 API 的需求帮助我们做出更好的容量规划决策。

这种学习规模很重要。我们的模型现在触达超过十亿活跃用户和超过两百万家企业。随着人们对技术的信心增长，他们更深入地使用它。注册六个月后，人们每天发送的消息量大约增加 50%，使用 ChatGPT 的工作种类大约翻倍。ChatGPT Work 正在改变知识工作者的含义，从回答问题转变为完成复杂的多步骤工作——从"问"到"做"。在整个 OpenAI，通过 Codex 进行的智能体工作现在占每周输出 token 的 99.8%，财务团队是将智能体工具作为工作主要部分的团队之一。

在组织内部，模式类似。一家公司可能从一个团队或一个工作流开始。随着质量和经济性的改善，采用扩展到各职能，AI 成为业务运营方式的一部分。

这在需求、产品改进、效率和基础设施规划之间创造了有价值的反馈循环。它不要求我们拥有每一项资产或自行构建每一个组件。我们可以拥有、合作或购买，取决于什么最好地服务客户并在经济上最有意义。重要的是协调整个系统并在其中学习。

## 以信念和纪律来建设

AI 基础设施必须在其被需要之前数年进行规划，而模型、产品和客户需求演变要快得多。这种错配使纪律变得不可或缺。

我们基于证据做出投资决策：用户和工作负载增长、企业承诺、API 消费、利用率、收入以及模型能力和效率的进展。技术和商业里程碑帮助决定项目何时推进。长期合作伙伴关系将所需的融资、基础设施和运营专长汇聚在一起，以实现大规模交付。

产品收入、私募资本和商业合作伙伴关系在支持这一增长中扮演不同角色。目标不是建设最多的基础设施。而是在正确的时间、针对可信的需求部署正确的容量。

对我来说，关键问题很直接：新容量多快能变得有生产力？它的利用效率如何？它支持什么客户需求？技术进步能多快降低交付有用智能的成本？

这些问题将长期雄心与运营纪律连接起来。

## 前方的机遇

我们仍然处于早期阶段。更强大的系统将完成更长的项目、跨工具协调，并处理从想法到成品之间更多的工作。个人和小企业将获得曾经只有更大组织才能拥有的能力。企业将在其运营中更广泛地应用智能。

我们的目标不仅仅是更多算力、更大模型或更低 token 价格。而是触手可及的、更有用的智能。

这就是丰饶的含义：智能不断变得更强大、更经济、对使用它的人更有价值。我们将以它使多少有用工作成为可能、我们交付它的效率有多高、以及它的益处能多广泛地被分享来衡量我们的进展。
