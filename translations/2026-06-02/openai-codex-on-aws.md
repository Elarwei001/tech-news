# OpenAI 前沿模型与 Codex 全面登陆 AWS

> 本文为 AI 译介，基于 [OpenAI 官方公告](https://openai.com/index/openai-frontier-models-and-codex-are-now-available-on-aws/)进行完整编译，非逐字翻译。

---

OpenAI 今日宣布，其前沿模型和 Codex 现已在 AWS 上全面可用（Generally Available），为数百万 AWS 客户开辟了通过现有平台使用 OpenAI 的新路径。

对于企业而言，这消除了 AI 采用的最大障碍之一：将前沿 AI 通过现有的安全、合规、采购、计费和治理工作流引入生产环境。客户现在可以在他们已经信任的 AWS 控制框架下引入 OpenAI 能力，帮助更快地从评估阶段过渡到实际部署。

## 将 OpenAI 能力引入 AWS 环境

OpenAI on AWS 为企业提供了前沿 AI 能力、熟悉的 AWS 运营模式以及更快投入生产的路径。提供方式包括：

**Codex on Amazon Bedrock** 将 OpenAI 领先的软件工程 Agent 带入 AWS——该工具每周被超过 500 万人使用。它帮助团队在已有构建和交付环境中编写、审查、调试和现代化代码。

这些服务同时在 Commercial 和 GovCloud 区域提供。

## 帮助客户从兴趣走向实施

随着客户开始使用这些能力，AWS 路径有助于减少采购、安全审查和生产就绪方面的摩擦。通过在熟悉的 AWS 环境中提供 OpenAI 能力，组织可以减少在运营障碍上花费的时间，把更多精力投入到实际构建中。

## 下一步：Daybreak 网络安全能力

OpenAI on AWS 是一条更广泛路径的起点，旨在帮助客户将前沿 AI 引入已有的构建、治理和交付环境中。OpenAI 将继续扩展通过 AWS 提供的 OpenAI 能力，让团队以更少摩擦和更大信心从评估走向生产。

这包括 Daybreak 的未来可用性——OpenAI 改变软件构建和防御方式的愿景。Daybreak 包含网络安全模型和 Codex Security，旨在通过将安全代码审查、威胁建模、补丁验证、依赖风险分析、检测和修复指导整合到日常开发循环中，帮助网络防御者更早发现风险、更快行动，让软件更具韧性。

随着 Daybreak 等专业能力向客户开放，AWS 可以为安全团队提供一条重要路径，让他们利用已有的安全、治理、采购和运营框架来采用这些能力。
